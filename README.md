# Doff Time

3 to 8 cardboard cores are placed on a 10 foot shaft.
Trim blades remove the edges of the plastic web and a 3/4 inch gap between the cores.
The non-trim sections are wound around the cores.
You can calculate the time it takes for one doff by dividing the roll length by the line speed.
You can calculate the average time for each roll by dividing this by the number of rolls in one doff.
You can calculate the time to finish a pallet by multiplying this by the number of rolls on a pallet.

I perform this calculation every day at work, so I thought of making a simple calculator to make it easy.

I started building it by hand, then I asked Gemini a question. Then I asked more questions, and pretty soon the app was functional.

I spent the rest of the time removing a lot of the unnecessary stuff Gemini added that made the calculator not fit on a phone screen. I now feel satisfied that there is nothing more I can take away.
